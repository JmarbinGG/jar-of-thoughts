# Setup guide (for the person receiving the jar)

**Before you start:** phone, home WiFi name + password, USB power. The WiFi must be **2.4 GHz**.

1. Plug the jar into USB power and wait ~30 seconds.
2. On your phone, join the WiFi **Jar-Setup** (password: *the setup password you were given*).
3. A setup page should open by itself. If not, open a browser and go to `192.168.4.1`.
4. Pick your home WiFi, enter its password, save. The jar restarts and joins your WiFi.
5. On the same WiFi, open **http://jar.local**. If asked to log in: username `jar`, password = *the settings password you were given* (no prompt if none was set).
6. Set your **timezone** first, then pick colors, messages, idle glow, brightness and quiet hours.

**Using it:** glowing = they're thinking of you; press the jar to say you saw it. Pressing with no glow sends them a message. Double press = night mode (or a second message if enabled).

**Troubleshooting**
- `jar.local` won't load: wait a minute on the same WiFi, or use the IP address shown in the jar's Telegram messages.
- Changed WiFi / moved house: hold the button 10 s (ring goes white at 3 s), the jar restarts into Jar-Setup.
- Stuck: unplug for 10 s and plug back in.
